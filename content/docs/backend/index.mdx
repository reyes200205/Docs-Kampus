El repositorio [`backend-kampus`](https://github.com/WilbertDevMx/backend-kampus) contiene únicamente la API. La app móvil vive en su propio repositorio y consume esta API.

## Stack

| Componente | Tecnología |
| --- | --- |
| Framework | Laravel 13 (PHP 8.3) |
| Autenticación | Laravel Sanctum (tokens) |
| Base de datos | PostgreSQL 16 |
| Tiempo real | Laravel Reverb + Echo (chat y notificaciones de match) |
| Archivos | Bucket compatible con S3 (Cloudflare R2 / MinIO) |
| Videollamada | LiveKit, detrás de una interfaz `VideoCallProvider` |
| Pruebas | PHPUnit · Formato: Laravel Pint |

## Estructura

```
backend-kampus/
├── app/                # Modelos, controladores y lógica
├── bootstrap/app.php   # Rutas, middleware y manejo de excepciones
├── config/             # Configuración de Laravel
├── database/           # Migraciones, factories y seeders
├── routes/
│   ├── api.php         # Endpoints de la API (prefijo /api)
│   └── web.php
├── tests/              # Pruebas (Feature y Unit)
└── .github/            # CI y plantilla de pull request
```
