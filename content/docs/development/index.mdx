Esta sección explica cómo trabajamos en los repositorios de Kampus: cómo se nombran las ramas, cómo se escriben los commits, cómo se revisa el código y cuándo una tarea está terminada.

## Herramientas del equipo

| Herramienta | Para qué |
| --- | --- |
| [Plane](https://app.plane.so/utt-plane/) | Tareas (`T-XX`), sprints y cronograma |
| [Slack](https://app.slack.com/client/T0C3K8PBWG1/C0C3FBXP938) | Comunicación del equipo |
| GitHub | Código, pull requests y CI |
