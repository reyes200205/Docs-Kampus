<Callout title="Cambio respecto al documento entregado">
  El anteproyecto planteaba el frontend como una SPA en React + Vite. El equipo lo construye con **Expo (React Native Web)**: hoy se publica como aplicación web y la misma base de código podrá compilarse para iOS y Android más adelante. La página de [Arquitectura](/docs/project/unit-1/architecture) ya refleja este cambio.
</Callout>
