**Objetivo:** chat en tiempo real con imágenes entre matches; API de grupos y de zonas; selección de zona en el perfil; app desplegada en el entorno de pruebas; API de staff y de aprobación de grupos.

**Resultado:** el objetivo se cumple **en parte**. El backend del sprint está completo salvo los mensajes. En la app se terminaron la pantalla "Es un match" (T-12) y la selección de zona con "Cerca de ti" (T-36), y se agregó el perfil obligatorio por pasos (T-49, tarea nueva); las tres están en revisión. El chat y el mapa no empezaron, y el despliegue tiene la configuración pero todavía no una URL pública.
