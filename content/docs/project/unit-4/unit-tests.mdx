## Qué cubren las pruebas unitarias

| Archivo | Clase probada | Casos |
| --- | --- | --- |
| [`GeohashTest`](https://github.com/WilbertDevMx/backend-kampus/blob/develop/tests/Unit/GeohashTest.php) | `Geohash`: la celda de ~1 km de la vista "Cerca" | Codifica y decodifica el ejemplo de referencia; el centro de una celda regresa a la misma celda; una celda tiene 8 vecinas distintas; rechaza caracteres fuera del alfabeto; la distancia usa la fórmula de Haversine |
| [`ImageSanitizerTest`](https://github.com/WilbertDevMx/backend-kampus/blob/develop/tests/Unit/ImageSanitizerTest.php) | `ImageSanitizer` y `MasksEmail` | Borra el EXIF de un JPEG; conserva PNG y WebP; rechaza lo que no es imagen, los formatos no permitidos y las dimensiones enormes antes de abrir la imagen; reduce el lado largo sin deformar; endereza según la orientación del EXIF; enmascara correos para el log |
| [`LiveKitProviderTest`](https://github.com/WilbertDevMx/backend-kampus/blob/develop/tests/Unit/LiveKitProviderTest.php) | `LiveKitProvider` (Adapter de videollamada) | El token es un JWT firmado y limitado a una sala; crea salas con límite de participantes; cerrar una sala que ya no existe no es error; avisa si LiveKit falla o no está configurado |
| [`SmsTest`](https://github.com/WilbertDevMx/backend-kampus/blob/develop/tests/Unit/SmsTest.php) | `PhoneNumber` y `VonageSmsSender` (Adapter de SMS) | Normaliza números de México a E.164; Vonage recibe texto sin acentos; cada código cabe en un solo SMS; un rechazo de Vonage lanza excepción; sin llaves no se llama a Vonage |
| [`DeviceLabelTest`](https://github.com/WilbertDevMx/backend-kampus/blob/develop/tests/Unit/DeviceLabelTest.php) | `DeviceLabel`: el nombre del dispositivo en Sesiones | 10 navegadores y sistemas distintos, con un *data provider* |

Las llamadas a LiveKit y Vonage se simulan con `Http::fake()`: las pruebas no salen a internet ni gastan saldo.

## Cómo correrlas

```bash
php artisan test                         # todas
php artisan test --testsuite=Unit        # solo las unitarias
php artisan test --filter=GeohashTest    # una clase
XDEBUG_MODE=coverage php artisan test --coverage-text   # con cobertura (necesita Xdebug o PCOV)
```

Con Xdebug activo las pruebas tardan unas 10 veces más; para el día a día conviene apagarlo ([Instalación](/docs/backend/installation#límites-de-php-en-local)).
