## Qué hay

La documentación interna de Kampus reúne en un solo sitio lo que antes estaba repartido en los README de cada repositorio:

- **Backend**: instalación, configuración, comandos, CI y la API REST (autenticación y endpoints).
- **App móvil**: instalación, cómo verla en tu celular y solución de problemas.
- **Desarrollo**: flujo de ramas, commits, pull requests y Definition of Done.

Además tiene un buscador con <kbd>Ctrl</kbd> + <kbd>K</kbd>, un [changelog](/changelog) y este blog.

## Dónde se publica

El sitio se genera como archivos estáticos y se publica en **Cloudflare Workers**. El acceso está protegido con **Cloudflare Access**: solo las personas autorizadas pueden entrar.

## Siguientes pasos

Cada endpoint nuevo de la API se documenta como parte de la Definition of Done. Si quieres agregar algo, revisa [cómo documentar](/docs/development/documentation).
